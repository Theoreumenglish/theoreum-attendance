Operations Command Center

오늘 운영을 빠르게 판단하고, 모든 행동은 기록으로 남깁니다.

더오름 운영 포털은 단순 출결 화면이 아니라 출결, 학생 관리, 직원 책임성, 클리닉 개입, 학부모 리포트를 연결하는 내부 운영 시스템입니다. 출석 안정화 코드는 유지하고, 각 메뉴는 실제 업무 앱처럼 독립 화면으로 분리했습니다.

스캐너 설정 체크
  • ✅ 스캐너 조명 ON, 조준선/레이저 ON
  • ✅ QR Code Enable 또는 2D Code Enable 확인
  • ✅ Mobile Screen Reading 모드가 있으면 ON
  • ✅ HID Keyboard Mode 사용
  • ✅ Suffix Enter 설정 확인
학생 안내문
  • 📱 휴대폰 화면 밝기를 최대로 올립니다.
  • 📏 QR과 스캐너는 15~30cm 정도 떨어뜨립니다.
  • ✨ 화면을 살짝 기울여 반사를 줄입니다.
  • 🔊 삑 소리가 난 뒤 화면을 닫습니다.
  • 🔁 계속 안 되면 QR 예외 학생으로 등록해 학번 4자리 출결을 사용합니다.
