# year-round-product-strategy-v1

## 목적

더오름 운영 OS는 시험기간 전용 도구가 아니다. 시험기간은 사용 강도가 가장 높은 대표 상황일 뿐이며, 제품의 본질은 **상시 학원 운영 누락 방지 OS**다.

## 제품 정체성

더오름 운영 OS는 다음 업무를 하나로 연결한다.

1. 출결
2. 미등원 확인
3. 단어 기록
4. 재시험 추적
5. 클리닉 생성/완료/미완료 관리
6. 학생360
7. 알림 실패 후속처리
8. 학부모 리포트
9. 직원 업무 책임성
10. 학생/학부모 링크 포털
11. 온라인강의 접근/시청 관리

## 시험기간의 위치

시험기간 기능은 중요하지만 제품 전체가 아니다.

- 상시 운영: 매일 출결, 단어, 클리닉, 알림, 학생 상태를 관리한다.
- 시험기간 운영: 상시 축적된 데이터를 바탕으로 위험 학생, 미완료 과제, 재시험, 보강, 리포트를 더 강하게 운용한다.
- 상담/리포트: 시험기간뿐 아니라 매월/매주 학습 흐름을 근거로 설명한다.

## 더클래스와의 역할 분리

더클래스가 결제/기본 학원관리 역할을 담당한다면, 더오름 운영 OS는 그 기능을 중복 개발하지 않는다.

- 결제/수납/청구: 더클래스 사용
- 더오름 운영 OS: 학습 운영, 누락 방지, 개입 기록, 리포트 근거, 학생/학부모 학습 포털
- 중복 기능보다 연결/보완 기능을 우선한다.

## 경쟁력의 핵심

범용 학원관리 프로그램과 차별화되는 핵심은 다음이다.

- 영어학원 특화 단어 미달 추적
- 단어 미달 → 재시험 → 클리닉 → 리포트 연결
- 미등원/미완료/알림 실패가 운영보드에 남는 구조
- 학생360에서 출결/단어/클리닉/리포트 흐름을 한 번에 판단
- 학부모에게 “무엇을 했는지”가 아니라 “어떤 근거로 어떻게 관리 중인지” 설명
- 학생에게 오늘 해야 할 학습/클리닉/온라인강의 링크를 바로 제공

## 당장 만들지 않는 것

- 카드 결제 처리
- 자동이체
- 청구서 발행
- 현금영수증
- 더클래스와 겹치는 full 수납 기능
- 무거운 native 앱 우선 개발

## 반드시 포함할 것

- 학생 링크 포털
- 학부모 링크 포털
- 온라인강의 링크/시청 관리 기반
- 내부 운영 OS와 외부 링크 포털의 데이터 연결
- 개인정보/권한/공개 범위 분리
