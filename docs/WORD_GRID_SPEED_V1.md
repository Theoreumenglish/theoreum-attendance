# word-grid-speed-v1

단어시험 일괄 입력을 실무형으로 빠르게 처리하기 위한 UI/UX 패치입니다.

## 적용 범위

- `public/admin.html`
- `scripts/ops-checklist.mjs`

Supabase SQL, 중앙DB GAS, Vercel 환경변수 변경은 없습니다.

## 주요 기능

1. 단어 일괄 입력 도구
   - 전체 / 미입력 / 불통과 / 미응시·면제 / 오류 필터
   - 빈칸 미응시 일괄 처리
   - 불통과 목록 복사
   - 점수 붙여넣기 적용

2. 엑셀형 입력
   - 점수 칸에 여러 줄 붙여넣기
   - 학생 ID + 점수 형태 붙여넣기
   - Enter / ArrowDown 다음 학생 이동
   - Shift+Enter / ArrowUp 이전 학생 이동
   - ArrowRight 상태 선택으로 이동

3. 빠른 표기
   - `a`, `abs`, `미응시`, `결석` → 미응시
   - `e`, `ex`, `면제` → 면제
   - `18/20` → 18로 처리

4. 저장 전 검증
   - 전체 개수보다 큰 맞은 개수 차단
   - 음수/소수/문자 입력 차단
   - 통과/불통과 상태인데 맞은 개수가 없는 행 차단
   - 오류 필터로 문제 행만 표시

5. 저장 후 처리
   - 불통과가 있으면 자동으로 불통과 필터를 보여줌
   - 기존 WORD_FAIL 클리닉 자동 생성/정리 흐름은 유지됨

## 운영 테스트

1. 단어시험 회차 선택
2. 반 명단 불러오기
3. 첫 번째 점수 칸에 여러 줄 점수 붙여넣기
4. `a`, `e`, `18/20` 단축 입력 확인
5. 전체 개수보다 큰 숫자를 넣고 저장 차단 확인
6. 빈칸 미응시 처리 확인
7. 불통과 목록 복사 확인
8. 전체 저장 후 결과 확인
