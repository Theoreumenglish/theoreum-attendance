# payment-scope-decision-v1

## 결정

더오름 운영 OS는 당분간 결제/수납 처리 기능을 만들지 않는다.

## 이유

더오름은 현재 더클래스를 통해 결제 처리를 하고 있다. 결제, 수납, 청구, 현금영수증, 자동이체 기능은 범용 학원관리 프로그램이 이미 강하게 제공하는 영역이며, 더오름 운영 OS가 같은 기능을 중복 개발해도 경쟁력이 낮다.

## 현재 원칙

- 결제 처리: 더클래스 사용
- 청구/수납/현금영수증: 더클래스 사용
- 더오름 운영 OS는 결제 프로그램이 아니다.
- 더오름 운영 OS는 학습 운영/누락 방지/리포트 근거/학생·학부모 학습 포털에 집중한다.

## 나중에 필요한 경우

향후 필요하면 직접 결제 기능이 아니라 가벼운 참조/연결 수준으로 다룬다.

예:

- 더클래스에서 export한 수납 상태 참고
- 미납 학생에게 학습 운영과 무관한 자동 조치 금지
- 결제 데이터는 학습 리포트와 분리
- 개인정보/회계 데이터 접근 권한 별도 관리

## 만들지 않는 것

- 카드 결제
- 자동이체
- 청구서 발행
- PG 연동
- 현금영수증
- 급여/회계 정산
