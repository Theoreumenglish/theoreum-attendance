# STAFF_PHONE_ONLY_ASSIGNMENT_V1

## 목적
기존 직원 계정의 비밀번호/PIN/권한을 건드리지 않고 출퇴근용 휴대폰 번호만 할당한다.

## 관리자 사용법
직원 메뉴 → 중앙DB 직원 계정 관리:
1. 직원 목록 조회
2. 기존 직원 선택
3. 휴대폰 입력: `01055556666` 또는 `55556666`
4. `휴대폰만 저장` 클릭

## 저장 위치
- `staff_phone_directory`에 우선 저장한다.
- 가능한 경우 `staff` / `staff_snapshot` mirror에도 보강한다.
- `bridge.staff.upsert`를 호출하지 않기 때문에 비밀번호/PIN을 실수로 바꾸지 않는다.

## 주의
직원 전체 신규 생성이나 권한 변경은 기존 `직원 저장` 버튼을 사용한다.
기존 계정에 전화번호만 할당할 때는 반드시 `휴대폰만 저장`을 사용한다.
