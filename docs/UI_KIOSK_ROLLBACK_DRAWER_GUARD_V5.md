# ui-kiosk-rollback-drawer-guard-v5

## 목적

현장 키오스크는 터치 키패드나 단일 숨은 입력창보다, 기존의 큰 업무 버튼 4개와 `010-0000-0000` 분할 입력 구조가 더 안정적이다. 이 패치는 운영 피드백에 따라 키오스크를 그 구조로 되돌리고, QA가 반드시 `#kPhoneMid`, `#kPhoneLast`를 확인하도록 잠근다.

## 변경 사항

- 키오스크 첫 화면을 큰 버튼 4개 + `010-____-____` 입력으로 복구
- 화면 가상 키패드는 계속 제거 상태 유지
- QR/스캐너 보조 입력 `#kInput`은 숨김 유지
- `#kPhoneMid`, `#kPhoneLast`가 항상 렌더링되고 포커스가 유지되도록 보강
- 직원 출퇴근 패널은 화면 버튼으로 늘어놓지 않고, 층수 배지 2초 long press 또는 `staff` 입력어로 열 수 있게 유지
- kiosk static check와 ops checklist를 010 분할 입력 기준으로 되돌림

## 다음 단계

학생 관리/직원 관리 화면은 버튼 추가가 아니라 리스트-상세 분리, 우측 drawer, 더블클릭 편집, bulk action을 단계적으로 적용해야 한다.
