# UI Staff/Kiosk Operator v4

## 목표

운영자가 헷갈리는 버튼을 줄이고, 현장 입력 장비 기준으로 키오스크를 다시 정리한다.

## 변경

- 키오스크 가상 숫자패드 제거
- 물리 키보드/스캐너용 단일 입력창 도입
- 입력창 autofocus와 blur 복구 로직 추가
- Enter 입력 즉시 학생 출결/직원 출퇴근 처리
- 키오스크에 직원 출퇴근 열기 버튼 명시
- 직원 관리 테이블에 점진적 공개 패턴 적용
  - 체크박스 선택
  - 하단 플로팅 선택 바
  - 행 액션은 점 3개 메뉴로 이동
  - 상태/권한 뱃지 표시
- 직원 추가/수정 저장 버튼 명확화
- 새 직원 입력 버튼 추가
- 상태 토글/인증정보 변경은 행 메뉴로 이동

## 운영 방법

### 학생 출결

키오스크 첫 화면에서 휴대폰 뒤 8자리 입력 후 Enter.

### 직원 출퇴근

키오스크 첫 화면에서 `직원 출퇴근 열기` 클릭 후 직원 휴대폰 뒤 8자리 입력 후 Enter.

### 직원 추가/수정

관리자 화면 → 직원 관리 → 중앙DB 직원 계정 관리.

- 신규: 새 직원 입력 → ID/이름/휴대폰/권한 입력 → 직원 추가/수정 저장
- 기존 수정: 직원 목록 조회 → ⋯ → 선택해서 수정 → 수정 → 직원 추가/수정 저장
- 전화번호만 변경: 직원 목록 조회 → ⋯ → 휴대폰만 저장 → 휴대폰 확인 → 휴대폰만 저장
