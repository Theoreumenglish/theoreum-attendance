# UI/UX Refresh v1 — 클릭 우선 운영 화면

## 목적

운영자가 매일 보는 화면에서 class_id/staff_id를 직접 입력하는 동선을 줄이고, 목록에서 고른 뒤 클리닉·단어시험·미등원 예외·반 배정으로 이어지도록 정리했다.

## 핵심 변경

- 상단 작업 컨텍스트 바 추가: 현재 선택 클래스와 선택 학생을 항상 확인한다.
- 클래스 목록 자동 로딩: 로그인 후 클래스 선택 select가 자동으로 채워진다.
- 클래스 선택 동기화: 상단에서 고른 클래스가 클리닉, 단어시험, 미등원 예외, 클래스 관리 폼에 자동 반영된다.
- 담당 직원 선택: 클래스/학생DB의 담당 직원은 직원 목록 select로 고르고 staff_id는 자동 반영한다.
- 학생 검색 → 수강생 추가 연결: 클래스가 선택된 상태에서 학생DB 검색 결과를 고르면 수강생 추가 칸에 자동 입력된다.
- 차분한 디자인 리프레시: 카드, 입력칸, 테이블 hover, sticky context bar, focus state를 일상 업무용으로 정리했다.

## 운영 테스트

1. 로그인 후 상단 작업 클래스 select가 채워지는지 확인한다.
2. 작업 클래스를 선택한 뒤 클리닉 메뉴의 수업 클리닉 대상 클래스가 자동 반영되는지 확인한다.
3. 단어시험 메뉴에서 반 선택이 자동 반영되는지 확인한다.
4. 출결 → 미등원 문자 제외에서 반 선택이 자동 반영되는지 확인한다.
5. 클래스 메뉴에서 클래스 빠른 선택을 고르면 수정 폼과 수강생 명단이 함께 바뀌는지 확인한다.
6. 학생DB 검색 결과를 선택했을 때, 선택 클래스가 있으면 수강생 추가 칸에 학번이 자동 입력되는지 확인한다.
