# PHONE_SEGMENT_INPUT_V1

## 목적

키오스크 휴대폰 번호 출결 입력을 `010-____-____` 형태의 두 칸 입력으로 정리한다.

## 정책

- 학생과 직원은 모두 본인 휴대폰 번호로 출결/출퇴근한다.
- 화면에는 `010-`과 중간 하이픈만 고정 표시한다.
- `xxxx` 같은 placeholder 문자는 표시하지 않는다.
- 사용자는 가운데 4자리 입력 후 자동으로 다음 4자리 칸으로 이동한다.
- 두 번째 4자리까지 입력되면 자동 제출한다.
- QR은 보조수단으로 유지한다.
- 2차 직원 확인 기능은 이번 범위에서 제외한다.

## 운영 이유

- QR 스캔 성공률 문제를 줄인다.
- 학번 공유로 인한 대리 출석 리스크를 낮춘다.
- 학생/직원 모두 같은 입력 규칙을 사용해 안내 비용을 줄인다.

## 확인 시나리오

1. 등원 모드에서 `010-` 표시 확인
2. 가운데 4자리 입력 후 자동으로 뒤 4자리 칸 이동
3. 뒤 4자리 입력 후 자동 처리
4. 하원/이동/외출도 동일 확인
5. `staff` 입력 시 직원 모드 전환
6. 직원 모드에서도 동일한 `010-____-____` 입력 확인


## 2026-06-27 하드닝: 물리 키보드 입력 우선

현장 키오스크는 화면 키패드를 사용하지 않고 물리 키보드 입력을 기본으로 한다.

- 숫자 키 입력은 `010-____-____`의 가운데/뒤 4자리 칸으로 직접 라우팅한다.
- 가운데 4자리가 채워지면 자동으로 뒤 4자리 칸으로 이동한다.
- 뒤 4자리까지 채워지면 자동 제출한다.
- 뒤 칸이 비어 있는 상태에서 Backspace를 누르면 가운데 칸으로 돌아간다.
- `staff`, `staffin`, `staffout` 같은 직원 진입어와 QR 스캐너 입력은 숨겨진 raw input으로 라우팅한다.
- 전역 keydown이 보이는 전화번호 입력칸의 숫자 입력을 가로채지 않도록 한다.
- 화면에는 `010-`과 구분 하이픈만 표시하고 `xxxx` placeholder는 표시하지 않는다.
