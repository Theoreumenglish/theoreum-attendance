# UI/UX Clean Operator Mode v2

목표: 기능을 더 노출하지 않고, 처음 쓰는 직원이 바로 이해할 수 있는 화면으로 정리한다.

## 원칙
- 홈 화면은 검색 1개와 핵심 업무 4개만 먼저 보인다.
- 고급 기능은 숨기지 않고 왼쪽 메뉴와 `전체 기능 보기`로 접근한다.
- 조교/선생님은 “학생 이름 검색 → 필요한 업무 버튼” 순서만 알면 된다.
- 학생/직원 전화번호 출결 설정은 별도 설명 없이 버튼명만 보고 접근 가능해야 한다.

## 홈 핵심 업무
1. 오늘 미등원
2. 학생 번호
3. 직원 번호
4. 단어·클리닉

## 참고한 UX 기준
- 사용자의 실제 업무 언어를 쓴다.
- 기억해야 하는 버튼을 줄이고, 화면에서 바로 인식할 수 있게 한다.
- 기본 화면은 작고 명확하게, 고급 기능은 필요할 때만 펼친다.
