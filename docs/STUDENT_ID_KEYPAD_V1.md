# student-id-keypad-v1

## 목적

QR 스캔 성공률이 낮아 학생 출결 참여율이 떨어지는 문제를 해결하기 위해, 키오스크의 기본 입력 방식을 학번 4자리 숫자 키패드 중심으로 바꾼다.

## 변경 사항

- `index.html` 키오스크 화면에 큰 숫자 키패드 추가
- 4자리 입력 완료 시 자동 제출
- 지움 / 한 글자 삭제 버튼 추가
- 등원, 하원, 교실 이동, 외출/복귀 모드 라벨 표시
- 직원 QR 모드에서는 학생 키패드 숨김
- QR 스캔은 보조수단으로 유지

## DB 변경

없음.

## 확인 기준

- `npm run verify` 통과
- 키오스크 화면에서 학번 4자리 입력 후 자동 등원/하원 처리
- QR 스캔 기존 동작 유지
- 직원 QR 모드 기존 동작 유지
