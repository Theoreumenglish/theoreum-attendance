# UI/UX Refresh v2 — 딸깍 운영 화면

## 목표
- 운영자가 매일 봐도 부담 없는 차분한 SaaS형 화면으로 정리한다.
- `class_id`, `student_id`, `staff_id`를 직접 입력하는 상황을 줄이고, 상단 작업 클래스/선택 학생/상세 작업 패널에서 이어서 처리한다.
- 중앙DB 저장처럼 시간이 걸리는 작업은 화면이 즉시 반응하도록 `safe optimistic UI`를 적용한다.

## 포함 기능

### 1. 딸깍 업무 보드
상단 작업 클래스와 선택 학생을 기준으로 다음 작업을 바로 이어간다.

- 선택 반 명단
- 수업 클리닉
- 단어 일괄 입력
- 선택 학생 클리닉
- 학부모 리포트
- 미등원 예외

### 2. 우측 상세 작업 패널
클래스 행 또는 학생 검색 결과를 선택하면 우측 작업 패널이 열린다.

- 클래스 패널: 명단, 수업 클리닉, 단어 일괄 입력, 미등원 예외
- 학생 패널: 출결 보기, 클리닉 만들기, 단어 결과 입력, 리포트 만들기

### 3. Safe optimistic UI
다음 저장 작업은 버튼 클릭 즉시 하단 작업 상태가 뜬다.

- 클래스 저장
- 학생DB 저장
- 수강생 추가
- 클리닉 생성
- 단어 개별 결과 저장
- 단어 일괄 저장
- 미등원 예외 저장
- 리포트 스냅샷 저장

실제 중앙DB/Supabase 저장이 실패하면 실패 상태로 표시하고 오류를 유지한다.

### 4. 현장/태블릿 모드
상단 `딸깍 선택 모드` pill을 누르면 현장/태블릿 모드로 전환된다.

- 사이드 메뉴 축소
- 태블릿/모바일에서 가로 스크롤 메뉴 제공
- 입력폼 1열화
- 터치하기 쉬운 카드형 작업 보드 제공

### 5. 리포트 디자인 개선
학부모 전달 문구 영역을 JSON/mono 텍스트가 아니라 카드형 리포트 미리보기로 표시한다.

## 배포 후 확인
1. 로그인 화면이 차분한 카드형 화면으로 보이는지 확인한다.
2. 상단 작업 클래스 선택 후 딸깍 업무 보드의 6개 tile을 눌러본다.
3. 클래스 행 클릭 시 우측 패널이 열리는지 확인한다.
4. 학생 검색 결과 선택 시 우측 패널이 학생 작업으로 바뀌는지 확인한다.
5. 클래스 저장/학생 저장/클리닉 생성/단어 저장 시 하단 저장 상태 toast가 뜨는지 확인한다.
6. 리포트 미리보기 후 학부모 전달 문구가 카드형으로 보이는지 확인한다.
7. 태블릿 폭에서 메뉴와 폼이 깨지지 않는지 확인한다.
