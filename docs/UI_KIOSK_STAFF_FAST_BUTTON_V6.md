# ui-kiosk-staff-fast-button-v6

목적: 키오스크를 이전의 큼지막한 4개 학생 출결 버튼 + 010-0000-0000 분할 입력 구조로 유지하면서, 직원 출퇴근은 숨은 long-press/hotword에만 의존하지 않고 데스크 직원이 바로 누를 수 있는 빠른 버튼으로 제공한다.

변경 사항:
- 학생 키오스크 기본 구조 유지: 등원 / 하원 / 교실 이동 / 외출·복귀 4개 버튼.
- 학생 번호 입력 구조 유지: `010- [가운데 4자리] - [마지막 4자리]`.
- 직원 빠른 실행 버튼 추가: `직원 출근`, `직원 퇴근`.
- 직원 hotword 복구: 어느 입력창에 focus가 있어도 `staff` / `staffout` 입력을 감지해 직원 출퇴근 모드를 연다.
- hidden scanner input의 invalid pattern 제거로 Chromium console error를 방지한다.
- 관리자 콘솔 학생 검색 결과는 버튼 노출을 줄이고 우측 drawer 중심으로 이어가도록 정리한다.

운영 방식:
1. 학생은 기존처럼 출결 액션 버튼 4개 중 하나를 고른 뒤 휴대폰 뒤 8자리를 입력한다.
2. 직원은 `직원 출근` 또는 `직원 퇴근`을 누른 뒤 휴대폰 뒤 8자리를 입력한다.
3. 기존 staff hotword, floor long press는 보조 경로로 유지한다.
