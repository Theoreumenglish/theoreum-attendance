# UI/UX Task-first Revamp v1

## 목적
기능이 많아지면서 원장/조교/선생님이 메뉴 구조를 외워야 하는 문제가 생겼다. 이 패치는 “설명서를 읽는 UI”가 아니라 “오늘 할 일을 누르면 되는 UI”로 바꾸는 1차 대격변이다.

## 핵심 원칙
- 메뉴 이름보다 실제 업무 이름을 우선한다.
- 처음 쓰는 사람은 홈의 큰 카드만 눌러도 된다.
- 고급 설정은 뒤에 두고, 오늘 처리할 일과 전화번호 출결 설정을 앞으로 꺼낸다.
- 학생/직원 전화번호 설정처럼 운영상 자주 막히는 일을 바로가기 카드로 만든다.

## 추가된 UX
- `uxStartBoard`: 홈 상단의 쉬운 업무 시작판
- `uxTaskCard`: 미등원 / 학생 전화번호 / 직원 전화번호 / 단어·클리닉 / 학생 링크 / 운영 점검
- `runUxTask`: 업무 카드별로 필요한 화면으로 이동하고 필요한 입력칸에 focus
- 메뉴명 개선: 오늘 할 일, 학생 관리, 출결 확인, 단어시험, 문자/알림, 반 관리, 직원 관리, 설정/점검
- 명령 팔레트에 전화번호 출결 설정/학생 링크 명령 추가

## 운영자 사용법
1. 출근 후 `오늘 업무 시작`을 누른다.
2. 학생 전화번호를 넣어야 하면 `학생 전화번호 출결 설정`을 누른다.
3. 직원 전화번호를 넣어야 하면 `직원 전화번호 출퇴근 설정`을 누른다.
4. 단어/클리닉/학생 링크는 홈 카드에서 바로 들어간다.

## 다음 단계
