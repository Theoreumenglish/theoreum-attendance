# PHONE_IDENTITY_QUALITY_V1

## 목적

휴대폰 뒤 8자리 출결을 실제 현장에서 안정적으로 사용하기 위해 학생/직원 전화번호 데이터 품질을 사전에 점검한다.

## 범위

- 학생 출결: `students.student_phone`
- 직원 출퇴근: `staff` / `staff_snapshot`의 전화번호 계열 컬럼
- 입력 방식: 키오스크에서 `010-####-####` 중 뒤 8자리 입력
- 읽기 전용 점검: 데이터 수정 없음
- DB migration 없음

## 추가 API

`admin.phoneIdentity.audit`

권한: admin 이상

점검 항목:

- 학생 본인 휴대폰 번호 없음
- 학생 번호가 `010`으로 시작하는 11자리 형식이 아님
- 재원생 간 휴대폰 뒤 8자리 중복
- 재원생 간 전체 휴대폰 번호 중복
- 학생 본인 번호와 학부모 번호 동일 여부
- 직원 휴대폰 번호 없음
- 직원 번호가 `010`으로 시작하는 11자리 형식이 아님
- 재직 직원 간 휴대폰 뒤 8자리 중복
- 학생/직원 뒤 8자리 충돌

## 관리자 화면

설정 화면에 `휴대폰 출결 준비도` 카드를 추가한다.

- 휴대폰 출결 점검 버튼
- 수정 필요 목록 복사 버튼
- 학생/직원 출결 가능 비율
- 수정 필요/확인 권장 목록

## 운영 기준

- blocker: 키오스크 출결 실패 가능성이 높은 항목
- warn: 운영상 확인이 필요한 항목
- OK: 수정 필요 항목 없음

## 후속 작업

- 전화번호 누락/중복 수정 후 재점검
- 학생/직원 실제 키오스크 테스트
- 필요 시 v2에서 normalized phone identity cache 추가 검토


## 학생 학부모 번호 fallback
학생 본인 번호가 없거나 010 형식이 아닌 경우, 010 형식 학부모 번호를 출결 fallback으로 사용할 수 있다. 단 같은 학부모 번호가 여러 재원생에게 연결되면 뒤 8자리 중복으로 막는다.
