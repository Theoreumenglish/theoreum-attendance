# UI/UX Internal Minimal v3

목표: 판매용 설명 화면이 아니라 더오름 내부 직원이 매일 쓰는 운영 도구처럼 보이게 정리한다.

## 변경 기준

- 로그인 화면은 한 카드로 단순화한다.
- 장황한 설명 문구는 기본 화면에서 숨긴다.
- 클래스/학생 선택 후 바로 업무로 이어지는 흐름은 유지한다.
- 딸깍 업무 보드는 설명 카드 없이 작업 버튼만 남긴다.
- 전체 디자인은 흰색/회색 기반의 차분한 내부 업무 화면으로 정리한다.
- 필수 검사 문구와 접근성 구조는 유지한다.

## 확인 순서

1. 로그인 화면이 단순한 단일 카드로 보이는지 확인한다.
2. 로그인 후 상단 작업 클래스와 학생 검색이 바로 보이는지 확인한다.
3. 딸깍 업무 보드가 설명 없이 작업 타일 중심으로 보이는지 확인한다.
4. 클래스 → 클리닉 → 단어 → 미등원 예외 흐름에서 class_id 직접 입력 없이 선택으로 이어지는지 확인한다.
5. 태블릿 폭에서 메뉴와 작업 타일이 무너지지 않는지 확인한다.
