# online-lecture-linkage-v1

## 목적

더오름은 온라인강의를 많이 활용하므로, 운영 OS는 온라인강의를 후순위로 밀면 안 된다. 다만 v1에서는 자체 동영상 플랫폼을 만들지 않고, **온라인강의 링크/과제/시청 관리 기반**부터 만든다.

## v1 범위

초기에는 동영상 호스팅을 직접 만들지 않는다.

포함:

- 학생별 온라인강의 링크 등록
- 반별/학생별 강의 묶음
- 오늘 볼 강의 표시
- 강의 시청/완료 체크
- 미완료 학생 운영보드 표시
- 학부모 리포트에 온라인강의 수행 여부 반영
- 학생 링크 포털에서 강의 바로가기

제외:

- 자체 동영상 업로드/인코딩
- DRM
- 결제형 VOD
- 복잡한 LMS
- native app push 기반 학습 앱

## 운영 연결

온라인강의는 단독 기능이 아니라 클리닉/보강/과제와 연결한다.

예:

- 단어 미달 → 관련 복습 강의 링크 제공
- 클리닉 미완료 → 보강 강의 링크 제공
- 결석 학생 → 수업 보충 강의 링크 제공
- 시험 전 → 학교별 핵심 강의 묶음 제공

## 데이터 설계 후보

향후 additive migration 후보:

- `online_lecture_collections`
- `online_lecture_items`
- `student_lecture_assignments`
- `student_lecture_progress`
- `lecture_access_logs`

v1에서는 문서/링크 기반으로 시작하고, 실제 사용 패턴이 쌓인 뒤 DB를 확정한다.

## 리포트 연결

학부모에게는 단순 “강의를 올렸다”가 아니라 다음처럼 설명한다.

- 어떤 강의를 배정했는지
- 학생이 완료했는지
- 왜 이 강의가 필요한지
- 학원에서 다음에 무엇을 확인할지

이 구조가 온라인강의를 운영 OS 안의 개입 근거로 만든다.
