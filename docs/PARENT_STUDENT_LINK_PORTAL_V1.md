# parent-student-link-portal-v1

## 목적

학부모 앱과 학생 앱은 중요하다. 다만 초기에는 native 앱이 아니라 **모바일 웹 링크 포털**로 시작한다. 문자/카카오 알림 안의 링크로 접속할 수 있게 만들고, 사용성이 검증되면 앱으로 확장한다.

## 학생 링크 포털

학생은 링크로 접속해 오늘 해야 할 일을 확인한다.

초기 노출 항목:

- 오늘 수업
- 오늘 단어 범위
- 재시험 필요 여부
- 클리닉 예정/미완료
- 온라인강의 링크
- 과제/제출 안내
- 학원 공지

학생 포털은 실행 중심이다. 학생이 무엇을 해야 하는지 바로 보여주는 것이 목적이다.

## 학부모 링크 포털

학부모는 링크로 접속해 자녀 관리 상태를 확인한다.

초기 노출 항목:

- 최근 출결
- 단어 수행 흐름
- 클리닉 진행 상태
- 학원 조치 내용
- 리포트 요약
- 온라인강의 수강 안내
- 선생님 공유 메모

학부모 포털은 보고/신뢰 중심이다. 내부 메모와 학부모 공유 메모는 반드시 분리한다.

## 접근 방식

v1에서는 로그인 앱이 아니라 기간 제한 링크로 시작한다.

- 토큰 기반 링크
- 만료일
- 학생/학부모 구분
- 접근 로그
- 링크 폐기 가능
- 내부 메모 비노출
- 타 학생 정보 비노출

## 내부 OS와의 연결

학생/학부모 링크 포털은 별도 서비스가 아니라 내부 운영 OS의 공개 가능한 일부만 보여주는 창이다.

- 학생360의 parent_visible 데이터만 공개
- 리포트 스냅샷 기반 공개
- 클리닉 상태는 공개 문구로 변환
- 단어 결과는 과도한 낙인 표현 없이 요약
- 알림 발송 이력과 링크 접근 이력을 내부에서 확인
