# student-id-attendance-v1

## 목적

학생 QR 스캔 성공률이 낮아 학생들이 출첵을 포기하거나 짜증내는 문제를 줄이기 위해, 등원/하원 기본 입력 수단을 학번 4자리로 전환한다.

## 정책

- 등원/하원은 모든 재원생이 학번 4자리로 처리할 수 있다.
- 학생 QR은 삭제하지 않고 보조수단으로 유지한다.
- 교실 이동/외출·복귀는 기존처럼 학번 4자리 입력을 사용한다.
- `students.is_exception`은 더 이상 학번 출결 허용 조건이 아니다.
- `students.is_exception=Y`는 QR이 특히 어려운 학생을 표시하는 운영 메모로만 유지한다.

## 기록

학번 출결로 처리된 로그는 `attendance_logs.meta_json`에 다음 값을 남긴다.

```json
{
  "input_mode": "STUDENT_ID",
  "student_id_attendance": "Y"
}
```

QR로 처리된 로그는 기존처럼 `input_mode=QR` 및 `qr_id`를 유지한다.

## 기대 효과

- 출첵 성공률 상승
- 학생 대기/짜증 감소
- 조교 수동 개입 감소
- QR 실패로 인한 미등원 오탐 감소

## 리스크와 대응

- 다른 학생 학번 오입력 가능성: 화면에는 마스킹된 이름과 학번을 표시하고, 출결 로그는 append-only로 남긴다.
- 학번 공유 가능성: 초기 내부 운영 단계에서는 성공률을 우선한다. 추후 필요하면 학생별 PIN/생일 뒤 4자리 추가 확인을 검토한다.
- QR 기능 퇴화: QR은 보조수단으로 유지하되, 운영 안내 문구는 학번 중심으로 변경한다.
